Sample Element

The <samp> element is used to enclose inline text which represents sample output from a computer program. Its contents are typically rendered using the browser’s default monospace font.
Syntax- 

            <samp> Content </samp>
Example-
<p>I was trying to boot my computer, but I got this hilarious message:<br/><samp>Keyboard not found <br/> Press F1 to continue...</samp></p>

Output-

I was trying to boot my computer, but I got this hilarious message:
Keyboard not found
Press F1 to continue...
