Images

HTML <img> tag is used to embed an image in web pages by linking them. It creates a placeholder for the image, defined by attributes like src, width, height, and alt. It does not require a closing tag.
We can provide a full path or address (URL) to access an internet file. Also, we can provide the file path relative to the location of the current web page file.
Src specifies the image source URL.
Alt provides descriptive text if the image cannot be displayed. It also helps users with slow connection or broken image links.
The width and height attribute in the <img> tag defines the size of an image, with values specified in pixels by default.
The title attribute adds a tooltip to an image that appears when a user hovers it. Displays descriptive text on mouse hover.
The border attribute is used to control the border appearance of an image. It specifies the thickness of the image border. Setting border=”0” removes the border completely. It adds a visible outline, showing how an image's style can be adjusted. This demonstrates basic styling, modern styling can be done using CSS.
Image alignment in HTML controls how an image is positioned within a web page layout. Alignment is set using the align attribute in <img> tag. Common values include left, right, and center.

Common Image file formats (Format → Full Name →Extension)
PNG → Portable Network Graphics → .png
JPEG → Joint Photographic Expert Group Image → .jpg, .jpeg, jfif, pjpeg, .pip
SVG → Scalable Vector Graphics → .svg
GIF → Graphics Interchange Format → .gif
ICO → Microsoft Icon → .ico, .cur
APNG → Animated Portable Network Graphics → .apng

Syntax-
<img src="URL" alt="Alternative text">

Example-
<img src="https://th.bing.com/th/id/OIP.kf3rbDAdmf-urpG-Z05n-gHaH8?w=132&h=180&c=7&r=0&o=7&dpr=2.1&pid=1.7&rm=3" alt="Pikachu">
