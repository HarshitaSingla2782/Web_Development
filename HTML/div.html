Div Element

The <div> element is the generic container for flow content. As a “pure” container, the <div> element does not inherently represent anything. Instead, it's used to group content so it can be easily styles using the class or id attributes, marking a section of a document as being written in a different language (using the lang attribute), and so on. The <div> element should be used only when no other semantic element (such as article or nav) is appropriate.
Syntax- 

            <div> Content </div>
Example-
<div>
<p>Hello World</p>
<b>Lorem ipsum dolor sit amet.</b>
</div>

Output-

Hello World

Lorem ipsum dolor sit amet.
