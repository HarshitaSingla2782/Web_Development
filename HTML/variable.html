Variable Element

The <var> element represents the name of a variable in a mathematical expression or a programming context. It's typically presented using an italicized version of the current typeface, although that behavior is broser- dependent.
Syntax- 

            <var> Variable name </var>
Example-
<p>The volume of a box is <var>l</var> x <var>w</var> x <var>h</var>, where <var>l</var> represents the length, <var>w</var> represents the width, and <var>h</var> represents the height.</p>

Output-

The volume of a box is l x w x h, where l represents the length, w represents the width, and h represents the height.
