Audio Element

The HTML <audio> element embeds an audio file to the webpage. You can add an audio player inside a webpage using the <audio> element.
The <audio> element is used to enable the support of audio files within a web page. We can include multiple sources of audio; however, the browser will choose the most appropriate file automatically. Most of the attributes of <video> element is also compatible with the <audio> element. The most frequently used attributes of the HTML audio element are controls, autoplay, loop, muted, and src.

Below are some attributes used by <audio> element(Attribute →Description)
autoplay → It allows playing the audio automatically when the page is loaded.
controls → It adds built- in audio controls for play, pause, and volume.
loop → Specifies that the audio will restart automatically after it finishes.
muted → The audio will be muted by default when the page is loaded.
preload → Specifies how the audio should be preloaded by the browser.
src → Specifies the path of the audio file.

Syntax- 

            <audio>
                <source src="URL">
            </audio>
Example-
<audio controls>
<source src="6.mp3" type="audio/mp3"/>
</audio>
