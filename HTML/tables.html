Tables

HTML tables represent data, such as text, images, links, and other elements in a structural format with rows and columns. It allows clear presentation of data for comparison.
They are useful for displaying schedules, price lists, product details, and more.
HTML tables are built using tags like <table>, <tr>, <th>, and <td>. Tables are created using <table> tag which defines the structure for organizing data in rows and columns within a web page. <tr> defines the table row containing individual cells. <th> defines table header cell that typically holds titles or headings (usually bold and centered). <td> defines a standard table data cell that holds actual content.
<caption> provides a title or description for the entire table. <thead> defines the header section of a table, often containing column labels. <tbody> represents main content area of a table, separating it from the header or footer. <tfoot> specifies the footer section of a table, typically holding the summaries, or totals.
<col> defines attributes for table columns that can be applied to multiple columns simultaneously. <col> groups together a set of columns in a table to which you can apply formatting or properties collectively.

Colspan attribute is used to make a cell span more than one column. It stretches one cell across multiple columns.

Syntax-
<table> Content... </table>

Example-
<table style="width: 80%;">
<tr>
<th>Student</th>
<th>City</th>
</tr>
<tr>
<td>Garima</td>
<td>Bombay</td>
</tr>
<tr>
<td>Harshita</td>
<td>New Delhi</td>
</tr>
<tr>
<td>Tanu</td>
<td>Banglore</td>
</tr>
<tr>
<td>Naman</td>
<td>Chennai</td>
</tr>
</table>
