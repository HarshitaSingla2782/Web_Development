Links

HTML links, also known as hyperlinks, are used to connect one web page to another, allowing users to navigate easily between different pages, websites, or sections within the same page.
The <a> (anchor) tag creates hyperlinks, using the href attribute to specify the destination URL. It can link text, images, or buttons for navigation.

Absolute Link: An absolute link contains full URL (including protocol, domain, and path) to the resource. It always points to the same location, regardless of where the HTML file is located. It includes protocol (http:// or https:// ), domain name, and full path. Useful for linking to external websites or resources. It can be slower to update if the domain changes (you must update every link).

Relative Link: A relative link specifies the path relative to the current path's location. These are shorter and easier to maintain for internal links. It depends on the location of the HTML file. If the file structure changes, relative links may break. Ideal for internal navigation within the same website.

Note: An unvisited link is underlined and blue. A visited link is underlined and purple. An active link is underlined and red.

Syntax-
<a href=”URL”> Text here </a>

Example-
<a href="https://www.google.com/?zx=1774363602319&no_sw_cr=1">Click here to go to Google</a>

Output-
Click here to go to Google


Link with Target attribute

The target attribute in <a> tag specifies where to open the linked document. It controls whether the link opens in the same window, a new window, or a specific frame.
_blank: The link will open in the new browser window or tab.
Example-
<a href="https://www.google.com/?zx=1774363602319&no_sw_cr=1" target="_blank" title="Blank">Google</a>

Output-
Google


_self: The link will open in the same window or tab.
Example-
<a href="https://www.google.com/?zx=1774363602319&no_sw_cr=1" target="_self" title="Self">Google</a>

Output-
Google

_top: The link will open in the full body of the window.
Example-
<a href="https://www.google.com/?zx=1774363602319&no_sw_cr=1" target="_top" title="Top">Google</a>

Output-
Google


_parent: The link will open in the parent frame.
Example-
<a href="https://www.google.com/?zx=1774363602319&no_sw_cr=1" target="_parent" title="Parent">Google</a>

Output-
Google



Other ways to use Links

There are other ways with which you can use the links.
Link to an image: You can use an image as a link.
Example-
<a href="https://en.wikipedia.org/wiki/Mountain" title="Mountains"><img src="mountains.jpg" alt="Mountain" width="200" height="150"></a>

Output-



Link to an email address: You can create a link that opens the user's default email client.
Example-
<a href="mailto:example@example.com" title="Email">Email Us</a>

Output-
Email Us


Link to a phone number: You can create a link that opens the user's default phone client.
Example-
<a href="tel:+1234567890" title="Call">Call Us</a>

Output-
Call Us


Link to a button: You can create a button and use it as a link.
Example-
<a href="https://www.youtube.com/" title="Button"><button>YouTube</button></a>

Output-



Link to a download file: You can create a link that allows users to download a file and save it at the desired path.
Example-
<a href="mountains.jpg" title="Download" download>Download Mountains Image</a>

Output-
Download Mountains Image
