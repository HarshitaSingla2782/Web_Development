Favicon

A favicon is a small image displayed next to a website's title in the browser tab. It helps users quickly recognize and return to a website.
It appears in browser tabs, bookmarks, and browsing history for easy identification.
It improves brand recognition for by serving as a visual identity for the website. It enhances professionalism and credibility of the site. It improves usability by helping users locate their tab among multiple open tabs.

Favicon File Format Support (File Format → Browser Support → Quality)
ICO → All Five → Supports multiple icon sizes in a single file and provides wide browser compatibility
PNG → All Five → Supports high quality image, supports transparency, smaller file size
GIF → All Five → Provides animation
JPEG → All Five → Good for high quality images
SVG → All Five → Scalable, small file size, sharp quality at any resolution
WebP → All Five → Smaller file size with high quality

Example-
<link rel="icon" href="https://media.geeksforgeeks.org/wp-content/cdn-uploads/gfg_200X200.png" type="image/x-icon">

Output-
In the title bar of the browser, you will see the favicon displayed next to the website title.
