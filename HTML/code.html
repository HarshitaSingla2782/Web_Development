Code Element

The <code> element displays its contents styled in a fashion intended to indicate that the text is a short fragment of computer code. By default, the content text is displayed using the user's agent default monospace font.
Note: To represent multiple lines of code, wrap the <code> element within a <pre> element. The <code> element by itself only represents a single phrase of code or line of code.
Syntax- 

            <code> Code </code>
Example-
HTML Heading tag
<code><h1>Heading</h1></code>

Output-
<h1>Heading</h1>
