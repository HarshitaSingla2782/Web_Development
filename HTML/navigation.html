Navigation

The <nav> element is used to define the block of navigation links. It helps the search engines to understand the structure of a webpage, making navigation more accessible. The <nav> tag contains the links to other sections of the website, such as homepage or contact page.
The <nav> element is projected specially for primary navigation, such as menu or table of contents, rather than general hyperlinks in the document. We can use multiple <nav> within a single webpage.
Syntax- 

            <nav> .... </nav>
Example-
<nav>
<a href="#">Home</a>
<a href="#">Tools</a>
<a href="#">Dashboard</a>
<a href="#">Technology</a>
<a href="#">About</a>

Output-
Home Tools Dashboard Technology About
