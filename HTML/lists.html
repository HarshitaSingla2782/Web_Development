Lists

An HTML list organizes content into ordered or unordered format, makin information clear and easy to read. Lists organizes content using tags like <ul>, <ol> & <li>.

Types of Lists
There are mainly three types of lists-
1. Ordered List: Ordered lists are used when the items need to follow a specific sequence. In an ordered list, all the list items are marked with numbers by default. An ordered list starts with the <ol> tag, and each list item begins with the <li> tag.
Syntax- 

        <ol>
          <li>Item1</li>
          <li> Item2</li>
        </ol>
Example-
<ol>
<li>Apple</li>
<li>Mango</li>
<li>Orange</li>
<li>Pineapple</li>
</ol>

Output-

  1. Apple
  2. Mango
  3. Orange
  4. Pineapple

Attributes-
i. Reversed: It defines that order will be descending.
ol reversed attribute

  1. Pineapple
  2. Orange
  3. Mango
  4. Apple

ii. Start: It defines from which number or alphabet the order will start.
ol start attribute

  1. Pineapple
  2. Orange
  3. Mango
  4. Apple

iii. Type: It defines which type (1, A, a, I, and i) of the order you want in your list of numeric, alphabetic, or roman numbers.
ol type attribute

  1. Pineapple
  2. Orange
  3. Mango
  4. Apple

2. Unordered List: Unordered lists display items as bulleted points where the order of items does not matter, using the <ul> and <li> tags. Unordered lists are ideal for scenarios where the sequence of items is not important. This list is also known as bulleted list. An unordered list starts with the <ul> tag, and each list item begins with the <li> tag.
Syntax- 

        <ul>
          <li>Item1</li>
          <li>Item2</li>
        </ul>
Example-
<ul>
<li>Home</li>
<li>About Us</li>
<li>Contact Info.</li>
</ul>

Output-

  • Home
  • About Us
  • Contact Info.

Attributes-
i. Type: It specifies which kind of marker (disc, circle, and square) is used in the list.
ul type attribute with circle value

  • Holi
  • Diwali
  • Rakshabandhan

ul type attribute with square value

  • Holi
  • Diwali
  • Rakshabandhan

3. Description List: A description list is a list of terms, with a description of each term. These are useful for descriptions, glossaries, or any other key- value pairs of items. The <dl> tag defines the description list, the <dt> tag (description term) defines the term name, and <dd> tag (description details) describes each term.
Syntax- 

      <dl>
        <dt>Item1</dt>
        <dd>Description of Item1</dd>
        <dt>Item2</dt>
        <dd>Description of Item2</dd>
      </dl>
Example-
<dl>
<dt>Beverages</dt>
<dd> A beverage is any liquid intended for human consumption other than water, primarily consumed for hydration, refreshment, or pleasure rather than a full meal replacement. </dd>
<dt>Toys</dt>
<dd> An object for a child to play with, typically a model or a miniature replica of something. </dd>
</dl>

Output-
Beverages
A beverage is any liquid intended for human consumption other than water, primarily consumed for hydration, refreshment, or pleasure rather than a full meal replacement.
Toys
An object for a child to play with, typically a model or a miniature replica of something.
