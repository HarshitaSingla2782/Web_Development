Text Markup Tags

Headings- <h1> to <h6>

Headings are used to define the titles and subtitles of sections on a web page. They help organise the content and create a structure that is easy to navigate.
Proper use of headings enhances readability by organizing content into clear sections. Search engines utilize headings to understand page structure, aiding in SEO.
HTML offers six levels of heading tags, each serving a different purpose in structuring your content.
<h1>- Main Heading (Largest): Represents the primary focus of the page, usually used for the main title. Use only one <h1> tag per page for best SEO practices. Make it clear to both users and search engines what the main topic is.
<h2>- Subheadings: Ideal for dividing the content into major sections. If the content has further subsections, use <h3> to create a logical flow.
<h3> to <h6>- Smaller headings: These heading levels are used for finer subdivisions, gradually decreasing in size and importance.
<h3> is used for subsection under <h2>, while <h4> to <h6> are used for additional, less important subdivisions.
<h6> defines the least important heading.
Syntax-
<h2> Content.. </h2>

Example-
<h1> Main Heading </h1>
<h2> Subheading </h2>
<h3> Sub-subheading </h3>
<h4> Sub-sub-subheading </h4>
<h5> Sub-sub-sub-subheading </h5>
<h6> Sub-sub-sub-sub-subheading </h6>
Output-

Main Heading

Subheading

Sub-subheading

Sub-sub-subheading

Sub-sub-sub-subheading
Sub-sub-sub-sub-subheading

Paragraphs- <p>

HTML paragraphs are block- level elements that are used to structure and format text content on a web page. A paragraph is basically a collection of words and punctuation together. It allows us to organize and present textual information into coherent and readable manner. The HTML <p> tag is used to create paragraph element.
Paragraphs typically create space above and below the text, separating it from surrounding text.
Syntax-
<p> Content.. </p>

Example-
<p>Lorem ipsum dolor sit amet consectetur adipisicing elit. Atque nesciunt iste ipsam officia in ipsum voluptatum commodi perspiciatis nobis ad.</p>

Output-

Lorem ipsum dolor sit amet consectetur adipisicing elit. Atque nesciunt iste ipsam officia in ipsum voluptatum commodi perspiciatis nobis ad.

Line Breaks- <br>

It allows you to break text into new line without starting a new paragraph or block. This is helpful when you need to format text in a specific way, like in poems or addresses. For adding a line break, insert the <br> tag where the text should continue the next line.
To insert a line break, simply place the <br> tag at the point in your content where you want the text to start on a new line. It is a self- closing tag.
Syntax-
<br/>

Example-
<p>Lorem ipsum dolor sit <br/>amet consectetur adipisicing elit. Atque nesciunt iste ipsam officia in ipsum voluptatum commodi perspiciatis nobis ad.</p>

Output-

Lorem ipsum dolor sit
amet consectetur adipisicing elit. Atque nesciunt iste ipsam officia in ipsum voluptatum commodi perspiciatis nobis ad.

Horizontal Rule- <hr>

The <hr> tag represents a thematic break between content, often displayed as a horizontal line. It is a self- closing element and is used to visually or semantically separate sections of content.
Syntax-
<hr/>

Example-
<p>Lorem ipsum dolor sit <hr/>amet consectetur adipisicing elit. Atque nesciunt iste ipsam officia in ipsum voluptatum commodi perspiciatis nobis ad.</p>

Output-

Lorem ipsum dolor sit

amet consectetur adipisicing elit. Atque nesciunt iste ipsam officia in ipsum voluptatum commodi perspiciatis nobis ad.

Preformatted Text- <pre>

The <pre> tag defines preformatted text. Text in a <pre> element is displayed in a fixed width font, and the text preserves both spaces and line breaks. The text will be displayed exactly as displayed in the HTML source code. This is useful when you must display code, formatted text, and preserving text layout.
Syntax-
<pre> Content... </pre>

Example-
<pre>Lorem ipsum dolor sit
amet consectetur adipisicing elit. Atque nesciunt
iste ipsam officia in ipsum voluptatum commodi
perspiciatis nobis ad.</pre>

Output- 

Lorem ipsum dolor sit
        amet consectetur adipisicing elit. Atque nesciunt 
        iste ipsam officia in ipsum voluptatum commodi 
        perspiciatis nobis ad.
